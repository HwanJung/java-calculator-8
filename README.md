# java-calculator-precourse

### 입력
- [x] 사용자에게 문자열 받음

### 파싱
- [x] 커스텀 구분자 형식 식별
  - [x] "//" + 문자1개 + "\n" 패턴이 아니라면 예외
  - [x] 추출한 구분자가 숫자라면 예외
  - [x] 문자열에서 커스텀 구분자 패턴 제거
- [x] 문자열 형식 체크
  - [x] 문자열에 구분자와 숫자가 아닌 문자가 있으면 예외
  - [x] 구분자 사이에 숫자가 없다면 예외 
  - [x] 구분자가 맨 앞, 맨 뒤에 온다면 예외
- [x] 구분자를 기준으로 숫자 추출
  - [x] 문자열이 비어있으면 빈 리스트 반환

### 기능
- [x] 추출한 숫자 합 반환

### 출력
- [ ] 합 결과 출력
